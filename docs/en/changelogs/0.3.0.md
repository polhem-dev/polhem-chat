## Changes in behaviour

### The view's texts moved to `Polhem.Chat`

`ChatViewStrings` is now `ChatStrings`, in the `Polhem.Chat` package and namespace, so that views on other UI frameworks
can use the same texts and translations. Its members are the same, and `ChatView.Strings` takes the new type.

- Replace `ChatViewStrings` with `ChatStrings`, and add `using Polhem.Chat;` where the file has only
  `using Polhem.Chat.Avalonia;`.
- A subclass that overrides a formatting method keeps working once renamed.

`ChatStrings` also formats what the default templates showed through their own converters: `DescribeTurn` writes the
summary line of a turn, and `DescribeToolStatus` the word for the state of a tool call. Both are virtual, so an
application changes them the way it changes the other formats.

`VisibleText` is public in `Polhem.Chat`. It escapes the characters that draw nothing or reorder the text around them,
so that what the user reads is what a tool receives; a template of the application's own that shows tool arguments,
tool results or file names should show them through it.
