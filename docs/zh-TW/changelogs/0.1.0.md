# Polhem.Chat 0.1.0 — 發佈說明

[English](../../en/changelogs/0.1.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.1.0]` 條目的詳細內容。

兩個套件首次發佈：`Polhem.Chat` 是對話模型，把 Microsoft.Extensions.AI 任何 `IChatClient` 的串流更新轉成 UI 顯示的項目；
`Polhem.Chat.Avalonia` 提供 `ChatView` 控件，顯示這樣的對話並接收提問。對話模型不依賴任何 UI，所以這個控件只是顯示它的
其中一種方式。

各類應用程式要處理的事項：

- **所有應用程式**：無；這是第一個版本。

## 新功能與變更

### 對話模型（`Polhem.Chat`）

`ChatConversation` 同時保存兩樣東西：送給模型的歷史（Microsoft.Extensions.AI 的 `ChatMessage`），以及 UI 顯示的項目。
內建的項目型別有 `UserPromptEntry`、`AssistantReplyEntry`、`ReasoningEntry`、`ToolCallEntry`、`TurnSummaryEntry` 與
`ErrorEntry`；應用程式可以繼承 `ChatEntry` 加上自己的項目型別。`DescribeToolCall` 提供工具呼叫顯示的標題。

`ChatTurn` 把串流的 `ChatResponseUpdate` 隨到隨轉成項目：文字、推理、工具呼叫與結果、用量與錯誤。自己跑迴圈的應用程式
直接使用它：`AddUserPrompt`、`BeginTurn`、每段更新呼叫 `Apply`，最後以 `Complete`、`Stop` 或 `Fail` 結束這一輪。

`ChatRunner` 以任何 `IChatClient` 執行對話：送出提問、串流回覆、依要求停止，並記錄每輪的時間與 token。`MessageSending`
可以在送出前改寫或取消提問，`ResponseReceived` 回報每一輪的結果。要使用工具時，用 `UseFunctionInvocation()` 包住 client，
並把工具放進 `ChatRunner.Options`。provider 拋出的例外不會從 `SendAsync` 逸出：它會結束這一輪，保存在
`ChatTurnResult.Exception`，並顯示為 `ErrorEntry`。

`SaveHistory` 與 `LoadHistory` 保存與還原對話。每一輪的時間與 token 會附在該輪最後一則助理訊息上，所以摘要也會還原；
送給模型之前會先移除。

本套件依賴 `Microsoft.Extensions.AI.Abstractions` 10.4.0 以上。

### `ChatView` 控件（`Polhem.Chat.Avalonia`）

`ChatView` 有兩種顯示對話的方式。設定 `Runner` 時，控件透過 `ChatRunner` 送出與停止。只設定 `Conversation` 時，控件
只負責顯示，並觸發 `PromptSubmitted` 與 `StopRequested`，`IsGenerating` 由應用程式設定。

每種項目都有預設樣板，回覆透過 `Polhem.Markdown.Avalonia` 以 Markdown 呈現。應用程式在控件上或更上層註冊的
`DataTemplate` 優先於內建樣板，所以應用程式可以加上新的項目型別，也可以改寫內建項目的外觀。

`ChatPromptBox` 按 Enter 送出、Shift+Enter 換行，輸入法確認組字的 Enter 不會送出。Esc 或停止鈕可以停止回覆，並保留已
收到的內容。完成的回覆可以複製 Markdown 原文。畫面會跟著新文字捲動，使用者往上捲之後改顯示「回到最新」。對話還是空的
時候，`Suggestions` 列出可以直接點選的提問。

`ChatViewStrings` 內建英文與繁體中文字串，可以替換。`ChatTheme` 加在基礎主題之後，在 Fluent 與 Semi 的淺色、深色下都能
使用；顏色是 `PolhemChat*` 資源，應用程式可以重新定義。

本套件依賴 `Polhem.Chat`、Avalonia 12.0.0 以上，以及 `Polhem.Markdown.Avalonia` 0.1.0 以上。
