# Polhem.Chat 0.3.0 — 發佈說明

[English](../../en/changelogs/0.3.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.3.0]` 條目的詳細內容。

各類應用程式要處理的事項：

- **有替換 view 文字的應用程式**：[view 的文字移到 `Polhem.Chat`](#view-的文字移到-polhemchat)。
- **有處理 `PromptSubmitted` 或 `AttachmentRejected` 的應用程式**：[view 的事件參數移到 `Polhem.Chat`](#view-的事件參數移到-polhemchat)。

## 新功能與變更

### `ChatComposer`

使用者對 chat view 做的事情，除了畫面本身以外，現在都由 `Polhem.Chat` 的 `ChatComposer` 承接：輸入框與附加的檔案、送出、停止、
重新生成與編輯上一則提問，以及核准或拒絕工具呼叫。`ChatView` 的屬性、命令與事件都沒有變，改由自己的 composer 完成這些事，
原有的測試不需修改即全部通過；其他 UI 框架的 view 直接使用同一個 composer，不必再實作一次。

- 和 view 一樣，可以搭配 `ChatRunner`，也可以搭配由應用程式自己驅動的 `ChatConversation`。
- 只在 `Connect` 與 `Disconnect` 之間追蹤 runner 與對話。view 顯示時連接、關閉時中斷，所以比 view 活得久的 runner
  不會留著指向它的處理常式。
- `AddAttachmentAsync` 接受檔名、大小（或讀取大小的函式）與開啟檔案的函式，讓各框架傳入自己的檔案型別；
  `ChatAttachmentLimits` 的檢查完全相同。

### `ChatPicturePreview`

`ChatPicturePreview` 從 PNG、JPEG、GIF、WebP 圖片的標頭讀出尺寸，判斷它是否小到可以預覽（`MaxPixels`、`MaxAspectRatio`、
`MaxFileSize`）。幾 KB 的檔案就可以宣告一張要好幾 GB 才能解碼的圖片，而附件也可能來自 `ChatAttachmentLimits` 沒檢查過的
歷史紀錄。Avalonia view 在解碼預覽之前會先用它檢查每個附件；應用程式自己的樣板若會顯示附件，也應該先這樣檢查。

### 活動切換鈕的名稱

`ChatStrings.ShowActivity`（「顯示推理與工具呼叫」）是活動列上那個切換鈕的提示與無障礙名稱，按下它會顯示模型的推理與工具呼叫。
Avalonia view 的切換鈕原本兩者都沒有，螢幕閱讀器只會念出它的符號。

## 行為變更

### view 的文字移到 `Polhem.Chat`

`ChatViewStrings` 改名為 `ChatStrings`，移到 `Polhem.Chat` 套件與命名空間，讓其他 UI 框架的 view 共用同一份文字與翻譯。
成員沒有變，`ChatView.Strings` 改用新型別。

- 把 `ChatViewStrings` 換成 `ChatStrings`；檔案原本只有 `using Polhem.Chat.Avalonia;` 的，加上 `using Polhem.Chat;`。
- 覆寫格式化方法的子類別，改名後即可繼續使用。

預設樣板原本用自己的 converter 產生的文字，也改由 `ChatStrings` 產生：`DescribeTurn` 產生一個 turn 的摘要行，
`DescribeToolStatus` 產生工具呼叫狀態的字樣。兩者都是 virtual，應用程式可以像替換其他格式一樣替換它們。

`VisibleText` 在 `Polhem.Chat` 裡改為公開。它把不會顯示、或會改變前後文字順序的字元轉成跳脫序列，讓使用者看到的就是工具
收到的內容。應用程式自己的樣板顯示工具參數、工具結果或檔名時，應該經過它。

### 能預覽的圖片變少了

判斷附加圖片能否預覽的檢查變嚴格了，Avalonia view 和新的 Blazor view 都一樣：

- GIF 會計算每一個 frame 的範圍，不只看標頭宣告的邏輯畫面。幾十個位元組的 GIF 可以宣告很小的畫面、卻帶一個
  20000 × 20000 像素的 frame，解碼器會把整張圖放大到 frame 的大小。這樣的 GIF 現在只顯示檔名。
- 超過 5 MB（`ChatPicturePreview.MaxFileSize`）的圖片只顯示檔名。小圖後面可以接任意多的資料，而 web view 會把整個檔案交給瀏覽器。

### view 的事件參數移到 `Polhem.Chat`

`PromptSubmittedEventArgs` 與 `ChatAttachmentRejectedEventArgs` 從 `Polhem.Chat.Avalonia` 移到 `Polhem.Chat`，因為
`ChatComposer` 也會引發它們。成員沒有變，`ChatView.PromptSubmitted` 與 `ChatView.AttachmentRejected` 照舊使用。
檔案裡用到它們、但只有 `using Polhem.Chat.Avalonia;` 的，加上 `using Polhem.Chat;`。
