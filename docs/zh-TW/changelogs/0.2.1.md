# Polhem.Chat 0.2.1 — 發佈說明

[English](../../en/changelogs/0.2.1.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.2.1]` 條目的詳細內容。

這一版改變視圖「回到最新」按鈕的外觀。沒有新增、移除或變更任何公開成員，`Polhem.Chat` 與 0.2.0 相同。

各類應用程式要處理的事項：

- **以文字尋找這個按鈕的應用程式**（UI 測試或自動化）：[按鈕不再顯示文字](#按鈕不再顯示文字)。
- **自訂顏色的應用程式**：[兩個新的主題資源](#兩個新的主題資源)。

## 新功能與變更

### 回到最新改為圖示

使用者往上捲動時出現的按鈕原本是文字按鈕，浮在對話上容易被忽略。現在改為帶淡陰影的圓形按鈕，浮在對話尾端：

- 沒有新內容進來時，顯示向下箭頭。
- 回覆進行中，顯示三個依序閃動的圓點，同時表示下方有新文字正在進來。

圓點只在按鈕顯示時閃動。點按後一樣捲到最後，並重新跟隨新文字。

### 兩個新的主題資源

與套件的其他顏色一樣各有淺色與深色兩組值，應用程式在自己的資源中宣告同名的鍵即可替換：

| 資源 | 用於 |
|------|------|
| `PolhemChatScrollButtonBackground` | 按鈕底色，接近不透明，因為它浮在文字上 |
| `PolhemChatScrollButtonDotBrush` | 閃動的圓點，預設為珊瑚橘 |

## 行為變更

### 按鈕不再顯示文字

`ChatViewStrings.JumpToLatest` 現在是按鈕的提示與無障礙名稱（`AutomationProperties.Name`），不再是按鈕的內容，螢幕閱讀器
仍會唸出它。

**要做的事**：以按鈕上顯示的文字尋找它的 UI 測試或自動化，改以無障礙名稱，或樣板組件 `PART_ScrollToLatest` 尋找。

應用程式自訂的 `ChatView` 控制項樣板會保留它自己宣告的按鈕：視圖不會以名稱尋找新按鈕的任何組件。
